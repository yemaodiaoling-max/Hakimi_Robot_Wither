# QQ 点名看视频

QQ 支持 B 站链接、小程序卡片和同会话里可见的视频附件。观看请求携带群友当前的问题，以及理解指代所需的少量上下文。指定视频直接进入观察，完整的公共片段观察可以复用。换一个问题时由 6.2 Sol 按新问题生成反馈。

观察结果按来源、时间范围和画面或音轨分类。B 站流程按最长 30 秒的片段覆盖时间线，优先安排开头、结尾和中间，原生附件也保留实际采样范围。部分完成时，`coverage_status` 和 `unobserved_intervals` 会标出缺口。转写来源随观察一路传到 Sol。

`feedback.answer` 面向 QQ 哈基米，`feedback.evidence_ids` 对应引用的观察。Sol 可以在已引用画面范围内选一个时刻。程序从原视频解码一张 JPEG，核实实际帧时间，最后在 QQ 当前会话、当前回合登记为 `F1`。QQ 哈基米可以在原有 `reply.send` 中选用它。截图取不到时仍可使用文字反馈。

QQ 的 `qq_model_calls` 保留各次调用的归属、状态及错误代码。在 `autonomous_video_only` 费用配置下，指定视频的观察、备用观察、恢复和 Sol 反馈都记入 `qq_video`，独立于 B 站自主刷视频的日、月上限。费用按实际回执入账，未结请求保留预留。只有 QQ 最终回复流程负责发送消息。
