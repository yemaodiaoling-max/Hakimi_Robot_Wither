# 人设驱动的自主观看

这次改动将普通视频从“按推荐顺序采集、偶尔理解”改为预算驱动的自主观看。人设沿用QQ哈基米，原始记忆独立，B站/直播/视频来源标签和双向摘要桥接继续保留。

## 一轮观看

1. 预算可用时读取推荐候选；已验证的观察模型结合可信人设、有限QQ共享摘要和最近实际观看历史，选择一个候选BV。推荐标题仅用于选择，不能写成已看内容。
2. 采集该视频真实音画，交给观察模型。在同次请求里返回事实事件、兴趣程度、继续/划走的决定、带证据的小结，以及可选的人设评论。尽量复用同次请求，避免额外整理和评论生成费用。
3. 原始观察写入独立观看记忆；兴趣、已理解区间和小结保存在观看历史中，供后续选片。模型没理解的片段不算观看记忆，选择理由也不算亲历。
4. 喜欢则在预算许可时继续看后面的片段；不喜欢则明确划走，保留已经观察到的内容。达到每视频片段上限时记录为抽样结束，不冒称看完整片。
5. 预算还没到下一次使用时间时等待，不采集并划过一批未理解的视频。

## 评论边界

按用户授权启用普通视频顶层评论，符合哈基米人设并绑定实际视频观察。每个视频最多一次提交、每天最多四次，相隔至少一小时，同一UP主每天最多两次，最长120字；四条是上限而非任务量。缺少可靠UP标识时不评论；升级前当天UP未知的旧提交保守占用UP额度，旧评论与未知发送状态均保留。

至少两个成功观察片段且去重后累计60秒，短于60秒的视频需完整覆盖才例外。失败片段、重复重放和仅下载的内容不累计；重建观看场次时重新积累评论资格。兴趣必须为high，引用本视频、同次场次足够新鲜且置信度至少0.9的直接观察。评论需包含具体观察细节，提示词要求有相关感受或问题、不泛赞、不猜测真实人物；程序额外过滤缺少细节及与近期评论相似的内容，但文本启发式不保证语义绝对正确。标题、推荐文字或其他视频的记忆不能授权发表评论。

观看记忆保留BV来源，QQ同步摘要前置BV并携带公开视频链接；历史已有真实BV也会补出展示，无需额外模型调用。未理解区间仍不能冒称已观看。

程序从固定B站视频详情接口取得aid，模型只能输出文本和已有证据引用，不能指定目标账号、接口、楼层或地址。网络提交前先持久记录，超时或不明确回执不自动重试。不根据“进程在运行”推断评论已成功，也不根据API受理承诺公开可见。

## 优先直播与预算

房间8729095131继续优先。开播检查改为120秒；连续两次明确下播才恢复普通视频。开播可能在下一次检查后才被发现，下播确认也会比旧版慢。切换仍保存书签并阻止旧推理结果写入新目标或发出旧候选。

当前已验证新接口的月记账硬上限为40美元，日硬上限4美元，并非人民币换算值；账本和不确定费用跨重启保留。计划额度为直播65%、普通视频25%、余量10%；分别平摊到当月天数，再按实际调用费用调整间隔。选片、观察与评论生成都计入普通视频费用。硬预算和软额度都不会因升级清零。未启用已验证接口配置时仍保持旧10美元/月限制。

这不是完整视频逐帧理解。目标是在有限费用内少选一些、尽量理解和记住选中的片段；摘要和模型判断仍可能遗漏或误解内容。
