模块

三个模块共用同一个记忆内核，可以任意组合；没启用的模块不会启动，也不会影响其它模块。

模型与 Key

所有模块都通过本机网关调用模型。默认使用 Google AI Studio 的 Gemini API；也可以填任何兼容 Gemini 协议的地址。

主人

“主人”的吩咐会被优先办妥，聊天时语气更亲近；桌宠的经历也记在主人的私聊里。

人设

性格、说话方式、桌宠和 B 站的口吻都是普通文本。改完点「保存这个人设」即可（单独保存，不需要点底部按钮）；「恢复默认」会删掉你的版本。保存后重启对应服务生效。
