关系图读法

亲笔 实线 · 辅助 虚线 · Terra 点线；Terra 群友关系另有紫色虚线底衬。

分数颜色：0–19 红、20–39 橙、40–59 灰蓝、60–79 青绿、80–100 绿。未知是“待了解”，不按 0 画数字。

边数字只在选中人物时显示，且只标相连边。亲笔无分时，群友-群友关系可用 Terra 同指标分数作紫色虚线视觉叠加；悬停会注明 Terra 来源，不是亲笔分，也不参与亲笔门槛。

关系线本身不表示单一方向；方向见悬停、选中边标注与右侧详情。
